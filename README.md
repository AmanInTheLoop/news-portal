# 📰 News Portal

A full-stack news portal application that allows users to explore news articles, view detailed stories, and manage their own published content. The platform provides a responsive interface and a backend API for handling news and user-related operations.

## 🌐 Live Demo

**Live Website:** https://news-portal-tuws.vercel.app/

**GitHub Repository:** https://github.com/AmanInTheLoop/news-portal

## ✨ Features

- **News Homepage:** Browse featured and latest news articles.
- **News Listing:** Explore available news articles.
- **News Details:** Read individual articles on dedicated pages.
- **User Authentication:** Register and log in to an account.
- **News Management:** Create, update, and delete your own news articles.
- **User Dashboard:** Manage your account and published content.
- **Profile Management:** View and manage user profile information.
- **Contact Page:** Send messages through the contact form.
- **Responsive Design:** Access the application across different screen sizes.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm
- MongoDB database

### 1. Clone the Repository

```bash
git clone https://github.com/AmanInTheLoop/news-portal.git
cd news-portal
```

### 2. Install Backend Dependencies

```bash
cd backend
npm install
```

### 3. Configure Environment Variables

Create a `.env` file inside the `backend` directory and configure the required environment variables according to your backend configuration.

### 4. Start the Backend Server

```bash
npm run dev
```

### 5. Install Frontend Dependencies

Open another terminal:

```bash
cd frontend
npm install
```

Configure the frontend API URL using the environment variable expected by your frontend configuration.

### 6. Start the Frontend

```bash
npm run dev
```

The frontend and backend should now be running locally.
